# Custom Persona Plugin (自定义人设插件)

这是一个全局生效的 Antigravity 插件，用于自由定义与动态切换 AI 助手的对话风格与人设。

---

## 🎯 设计原则
- **代码与方案绝不妥协**：人设只管说话语气与交互氛围，涉及代码、排查和架构等技术内容永远保持最高专业水准与严谨度。
- **全局生效**：对所有对话、所有项目全局生效。
- **随时开/关与切换**：支持界面一键开关、对话即时口令切换、随时更换人设内容。

---

## 🛠️ 使用与控制方式

### 1. 对话即时控制（推荐，最省心）
无需手动改文件，直接在对话框中告诉我即可：
- **切换人设**：`把人设换成：毒舌但靠谱的代码老炮，喜欢一针见血`
- **临时关闭**：`严肃模式` 或 `关闭人设`（立即切回纯净专业工程师风格）
- **重新开启**：`开启人设` 或 `恢复人设`
- **查看当前人设**：`查看当前人设`

### 2. 手动修改配置
你也可以随时直接用编辑器打开 [AGENTS.md](rules/AGENTS.md) 自由修改「第三节：当前人设配置槽位」中的描述。

### 3. 系统级彻底关闭（硬开关）
在 Antigravity 界面左侧边栏的 **Skills & Customizations** (或 Plugins) 列表中，找到 `custom-persona`，点击开关切换为 Disabled 即可。
